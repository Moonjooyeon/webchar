# ASTRAL — Character Poster Editor

캐릭터 이미지로 애니메이션 포스터를 만들고 화면에서 직접 편집하는 웹 앱입니다.

## 실행

```sh
python3 -m http.server 4174 --directory dist
```

http://localhost:4174 에 접속합니다. `dist`는 정적 호스팅에도 사용할 수 있습니다.

## 기능

- 캐릭터 추가 및 전환, 등장 애니메이션
- 문구 더블클릭 편집, 요소 이동 및 크기 조절
- 레이어 검색, 순서 변경, 표시 및 잠금
- 선 굵기·내부 색상·불투명도·배경 그라데이션 편집
- 이동 가능한 편집 패널, 실행 취소 및 다시 실행
- 브라우저 자동 저장 및 현재 포스터 HTML 다운로드

브라우저 저장 내용은 해당 기기에 보관됩니다. 다운로드한 HTML은 편집 도구를 제외한 감상용 포스터입니다.

## 배경 제거 번들 빌드

```sh
npm ci
npm run build
```

배경 자동 제거는 모델 다운로드를 위해 네트워크 연결이 필요할 수 있습니다. 관련 라이선스는 `dist/BACKGROUND-REMOVAL-LICENSE.txt`를 확인하세요.

포함된 캐릭터 그림은 사용자 제공 이미지입니다. 별도 이용 허락을 의미하지 않습니다.
